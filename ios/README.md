# پینگو

اپ شخصی ویجت برای آیفون با یازده ویجت فارسی: تقویم شمسی، پیشرفت زمان، شمارش معکوس، ماه، یادداشت، قاب عکس، ساعت، فهرست کار، شمارنده، فال حافظ و زنجیره عادت. دو کنترل برای کنترل سنتر دارد، هر ویجت تنظیم جدا برای خودش دارد، پشتیبان‌گیری و بازیابی داخل اپ هست و روز آخر اعتبار نصب یادآوری می‌فرسته.

## نصب بدون مک

مک لازم نیست. فایل `Pingo.ipa` رو خود گیت‌هاب می‌سازه (workflow با نام `ios`، خروجی `Pingo-ipa`) و روی سایت قرار می‌گیره. این فایل با Apple ID رایگان روی کامپیوتر خودت دوباره امضا می‌شه. نیازها: آیفون با iOS 18 یا بالاتر، کابل و یه Apple ID رایگان.

### ویندوز

1. iTunes و iCloud رو از سایت خود اپل نصب کن، نه از Microsoft Store.
2. Sideloadly رو از https://sideloadly.io/ بگیر و نصب کن.
3. گوشی رو با کابل وصل کن، قفلش رو باز کن و Trust بزن.
4. `Pingo.ipa` رو بکش توی Sideloadly، Apple ID رایگانت رو بنویس و Start رو بزن. گزینه حذف اکستنشن‌ها (Remove app extensions) باید خاموش بمونه، چون ویجت همون اکستنشنه.

### مک

1. Sideloadly رو از https://sideloadly.io/ بگیر. iTunes لازم نیست.
2. گوشی رو با کابل وصل کن، قفلش رو باز کن و Trust بزن.
3. `Pingo.ipa` رو بکش توی Sideloadly، Apple ID رایگانت رو بنویس و Start رو بزن. گزینه حذف اکستنشن‌ها باید خاموش بمونه.

### لینوکس

1. Impactor رو از Flathub (`dev.khcrysalis.PlumeImpactor`) یا از https://github.com/claration/impactor/releases (فایل AppImage) نصب کن. بسته `usbmuxd` هم باید نصب باشه (`sudo apt install usbmuxd`).
2. گوشی رو با کابل وصل کن، قفلش رو باز کن و Trust بزن. اگه Impactor گوشی رو ندید، برنامه رو ببند و دوباره باز کن.
3. `Pingo.ipa` رو بکش توی Impactor، Apple ID رایگانت رو بنویس و نصب رو بزن.

Impactor روی ویندوز و مک هم کار می‌کنه و اگه Sideloadly ویجت رو درست نصب نکرد، جایگزین خوبیه.

### بعد از نصب، روی گوشی

1. تنظیمات، حریم خصوصی و امنیت، Developer Mode رو روشن کن. گوشی ری‌استارت می‌شه و رمز رو می‌خواد.
2. تنظیمات، عمومی، مدیریت VPN و دستگاه، زیر Developer App روی Apple ID خودت بزن و Trust کن.
3. اپ رو یک بار باز کن و ویجت‌ها رو به صفحه اصلی اضافه کن.

### اگه خطا دیدی

| مشکل | کار |
| --- | --- |
| گزینه Developer Mode نیست | بعد از اولین نصب پایین صفحه حریم خصوصی و امنیت پیدا می‌شه. |
| اپ باز نمی‌شه و توسعه‌دهنده معتبر نیست | Trust کردن حساب، مرحله ۲ بالا. |
| بعد از هفت روز اپ و ویجت‌ها کار نمی‌کنن | همون فایل رو با همون ابزار و همون Apple ID دوباره نصب کن. اطلاعات می‌مونه، ولی قبلش از بخش پشتیبان‌گیری اپ فایل بگیر. Sideloadly روی ویندوز و مک می‌تونه خودش تمدید کنه. Impactor روی لینوکس تمدید خودکار نداره. |
| خطای Cannot activate more than 3 apps | هر Apple ID رایگان فقط سه اپ همزمان داره. یکی از اپ‌های قبلی رو پاک کن یا Apple ID دیگه بساز. |
| خطای You cannot register more than 10 App IDs within a 7 day period | هر Apple ID رایگان ده App ID در هفت روز داره. پینگو دو تا مصرف می‌کنه (اپ و ویجت) و یه App Group هم می‌سازه. یه هفته صبر کن یا Apple ID دیگه بساز. |
| ویجت خالیه یا توی فهرست نیست | اپ رو یک بار باز کن، گوشی رو ری‌استارت کن و ویجت رو دوباره اضافه کن. اگه درست نشد، پینگو رو پاک کن و با Impactor نصب کن. |

اپ خودش شناسه App Group رو از پروفایل امضا می‌خونه، پس لازم نیست ابزار نصب شناسه رو دقیقاً همون بذاره.

## نصب با Xcode

فقط برای کسی که مک داره و می‌خواد از سورس بسازه. نیازها: مک، Xcode 26 یا بالاتر، آیفون با iOS 18 یا بالاتر.

1. `brew install xcodegen`
2. داخل همین پوشه `xcodegen` رو بزن تا `Pingo.xcodeproj` ساخته بشه.
3. اگه لازم شد شناسه‌ها رو داخل `project.yml` عوض کن (`PINGO_BUNDLE` و `PINGO_GROUP`)، چون شناسه باید روی اکانت خودت یکتا باشه.
4. پروژه رو باز کن و برای هر دو تارگت `Pingo` و `PingoWidgets` داخل Signing همون Team رایگان خودت رو بذار.
5. آیفون رو با کابل وصل کن، Developer Mode رو روشن کن و Run بزن.
6. داخل تنظیمات گوشی، بخش مدیریت دستگاه، حساب خودت رو Trust کن.

هر بار `xcodegen` رو دوباره بزنی، Team انتخاب‌شده پاک می‌شه و باید دوباره انتخابش کنی.

اعتبار نصب با اکانت رایگان هفت روزه. هفته‌ای یک بار با کابل Run بزن تا تمدید بشه.

## ساخت فایل IPA

روی گیت‌هاب با workflow `ios` ساخته می‌شه و نیازی به مک نیست. روی مک هم می‌شه `scripts/package.sh` رو اجرا کرد. خروجی داخل `landing/downloads` قرار می‌گیره و لینک دانلود سایت از همون‌جا کار می‌کنه. این فایل با شناسه و App Group پیش‌فرض ساخته می‌شه و باید با Sideloadly یا Impactor دوباره امضا و نصب بشه.
